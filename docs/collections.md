# 收藏与合集

依据Bookmark文档138–158、371–375、559–566、1192–1197段：Source保留永久来源，Collection只维护归集关系，不复制或覆盖正文/笔记。控制台独立入口使用收藏夹与有序合集卡片；收藏夹适合长期收纳，合集适合有顺序的课程/专题，两者本期均由空间成员手动管理。

本期明确模块：空间共享收藏夹/自定义合集创建、重命名、归档/恢复；从已接受的来源加入、移除、调整位置；同一来源可归入多个组，组内不重复。每空间最多100组、每组200项，列表读取超额拒绝而非静默截断。元数据版本冲突与成员关系更新采用同一个组版本；重试先重新读取，接口同状态操作不重复审计。写入复用身份/成员锁后重验及业务审计，租户复合外键/FORCE RLS/列授权。

不把手工归集当平台收藏夹同步。第二阶段：CSV/JSON明确字段映射及导入预览→用户确认→复用sources批次去重；平台来源/外部ID/授权和分页游标另建有消费者的接口。第三阶段：官方授权平台Adapter/公开合集分页发现→增量去重→原source计划/任务队列；撤权停止、未知副作用阻重发。浏览器扩展不得上传Cookie。以上尚未实现能力必须在UI单列，不能以手动粘贴普通URL计通过。

API契约：GET/POST /collections，PATCH /collections/{id}，GET /collections/{id}/items，PUT /collections/{id}/items/{source_id}。查询参数均拒绝；写入要求expected_version及active，位置为0–199，同位置以source_id稳定排序，未承诺连续序号。归档保留关联和位置但禁止新加入/恢复/调整；可移除已有项。读取来源链接仅文本显示，跳转或采集走既有安全边界。本模块不自动外网请求、模型调用或学习状态变更。
