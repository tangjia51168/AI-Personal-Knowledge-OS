# 学习状态与提醒

学习状态属于用户与笔记的关系，不修改不可变笔记修订。每位有效空间成员可以保存四种状态：未看、已看、粗看、细看，并可保存一个提醒时间。查询 `due=true` 只返回真实保存且已到期、尚未细读的记录。

提醒时间是到期记录，不代表系统已经发送邮件、浏览器通知或推送；当前没有外部通知消费者。状态变更写入 `learning.updated` 审计事件，并受成员身份、租户上下文、FORCE RLS 和复合外键保护。

提醒输入必须带时区，页面使用本机时间后转换为UTC；精确 `note_id` 查询不受普通列表100条上限影响。写操作等待空间锁后再次验证会话；锁等待期间注销不能继续保存。列表最多100条，页面明确披露，不把数量当作学习完成率。Chrome覆盖真实保存/刷新、细看排除到期、断网清除旧状态及手动重试；32表同机备份恢复包含学习时间/审计和应用角色RLS。

账户学习区另提供[个人学习进度总览](learning-summary.md)：全量笔记身份计数，不受到期列表上限影响；无记录归未看且单独披露，版本变化不重置状态。所有后续变更遵循[维护约定](maintenance.md)。
