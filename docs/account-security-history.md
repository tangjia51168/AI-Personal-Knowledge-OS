# 账户安全历史

账户页登录后提供“账户安全历史”，手动刷新或加载更早记录，与当前工作空间无关。
只有当前有效账户能读取自己的记录；注销或切换登录令牌清空页面状态，不写浏览器持久存储。
接口为`GET /api/v1/auth/security-events?limit=20&cursor=<UUID>`，每页1–50条，
按(created_at,id)倒序；只返回事件ID、固定动作和UTC时间。游标不属于自身则返回404。
同源BFF仅放行该固定GET路径及cursor/limit，不接受用户ID参数。

固定0010迁移新增8种动作：注册、登录成功、注销当前会话、撤销全部会话、邮箱验证、
密码重置、登录失败、未验证邮箱的登录尝试。成功事件与身份变更同事务提交；
密码重置仍撤销全部会话，旧令牌无法查看历史。

失败登录记录的是“针对账户的尝试”，不证明由账户本人发起。
每用户/动作/数据库15分钟窗口最多一条；未知邮箱只形成一个匿名失败时间桶，用户无法读取。
并发通过唯一索引去重，记录先提交再返回原401/403；不保存邮箱、IP、密码、令牌或自由文本。
现有Redis限流仍先执行，超过限流的请求不会形成此记录。
这不是逐次尝试计数，也不包括全部失败恢复链接、限流事件或独立告警。

表使用FORCE RLS及自身上下文，运行角色只有SELECT/INSERT，不能UPDATE/DELETE。
匿名插入使用无显式冲突目标的DO NOTHING，避免冲突目标SELECT策略要求导致500；
未开放匿名SELECT，也未使用管理员连接写业务。既有账户不回填虚构历史。

真实验收覆盖成功身份流程/会话撤销、并发失败去重、匿名桶、自身分页/跨账户游标拒绝、
事务回滚和运行角色改删/伪造其他用户拒绝；Chrome验证真实页面及注销清空。
部署前仍需单独确定保留期限、账户删除流程、受控归档、独立防篡改存储和外部告警。
当前用户外键不级联删除历史；普通运行不能自行销毁记录。
本机加密导出与离线校验见[audit-archive.md](audit-archive.md)，归档只包含当前账户历史，
不向空间管理员提供其他账户的全局安全历史或匿名桶。
