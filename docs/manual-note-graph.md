# 人工链接局部图谱

知识笔记详情的「人工链接局部图谱」可手动读取当前笔记一跳或两跳内的有效人工链接。
页面提供无方向SVG、编号及可键盘操作的完整标题列表，可打开有权限的节点笔记。
节点标题/版本来自读取时的最新修订，与当前正在查看的历史版本无关。

## 范围与限制

- 仅消费0019已有的人工笔记链接，不新增表/迁移，不写笔记、任务、用量或审计。
- 链接固定 `method=manual`、`confidence=null`；只表示人工相关入口，不声明支持、反驳、因果或事实核验。
- 以中心笔记为0跳，确定性广度优先选取最多30节点、60边；先保留连通树，再填充节点间的其他有效边。
  达到上限时返回明确截断原因，不代表未展示链接不存在。它不是全空间图谱、语义图谱或证据图谱。
- 图中圆环表示人工链接最短跳数；节点位置、线长不代表语义相似度。
- 图谱是手动读取的快照，不自动轮询。其他客户端变更后需重新读取；本页关联/移除/刷新链接时旧图清空。
  切换范围、请求失败时不展示旧图；切换笔记/空间或卸载时取消读取。草稿保护沿用笔记页面。
- 不执行模型/平台请求，不提供自动关系、概念归并、向量检索、拖拽布局或图谱导出。

## 接口与安全

`GET /api/v1/spaces/{tenant_id}/notes/{note_id}/graph?depth=1|2`，默认1。
复用身份与有效成员授权，在事务Tenant Context内查询；不信任租户header。
根笔记必须属于授权空间，所有查询显式带租户过滤，并受现有FORCE RLS及复合外键保护。
响应含根ID、范围、节点最新标题/版本/来源类型/跳数、人工边创建及最后操作者/时间、截断原因和上限。
边的source/target只标识规范存储双端，不是语义方向。

根存在性、有效边、最新标题共3次数据库查询，不逐节点读取。
有效边库存最多读取1001条；依赖已有写入配额1000，超限以409 `GRAPH_INVENTORY_LIMIT`拒绝，而非静默截取库存。
缺失修订以409 `GRAPH_REVISION_MISSING`拒绝。
边集合来自一次查询，标题来自另一次查询，普通READ COMMITTED下不承诺跨表时间点一致或实时更新。

同源BFF仅放行精确GET路径和depth查询；重复、空值及非1/2值拒绝，其他查询不转发。
认证令牌仅转发至固定后端；响应no-store/nosniff；标题按React文本渲染，不执行HTML。

测试与实际验收结果见[PROGRESS](../PROGRESS.md)，不将算法单测视为真实数据库通过。
无schema变化，沿用0019恢复证据；本模块不代表完整产品图谱或公开上线条件完成。
