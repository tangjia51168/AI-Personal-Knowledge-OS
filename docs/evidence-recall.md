# 固定修订证据自测

知识笔记、研究固定版本和个人复习工作台可展开“证据自测”。读取当前修订JSON导出后，用概述及已有章节条目建立固定回忆提示，最多31张；不调用模型，不生成新事实或自动评分。个人理解与缺失章节不出题。

## 契约与边界

- 复用原GET指定修订JSON导出，API逐请求身份/成员/RLS与笔记-修订-快照关系核验；前端readerDocument/readerEvidence再次核对精确ID、所需引文、重复编号、长度/1MiB。无新API/schema/队列/供应商。
- 每张卡关联章节/索引和原文引用；先填1–4000字符回答，再展开固定笔记参考与精确原文。所有文本直接由React转义，不执行HTML、不自动打开来源链接。
- 自评“需要再练/自评已回忆”，本轮结束列出待练，允许只重练这些卡。计数只描述用户当前选择，不能解释为掌握率、事实正确率或系统判分；不修改阅读状态/提醒/完成时间。
- 状态仅在当前页面内存，组件切换保留；换版本/空间/会话、刷新或关闭工作台清空。没有服务器错题库、事件历史或跨设备同步。重复读取会明确重置本轮。
- 读取失败清空旧题/回答/自评，手动重试；取消挂载会中止请求。401沿统一会话清空全部工作区。题库只反映已保存笔记范围，前缀分析/导入未核验等限制由相邻阅读区继续展示；自测不能补足长文质量。

## 维护入口

`./scripts/check.ps1`包括纯函数证据/快照/修订边界与自测卡片引用守卫、TS/lint/build；`scripts/track_acceptance.py --track console --run browser`验证真实导出读取、先答后看、自评重练、修改失效、跨组件草稿、断网清空、历史版本隔离及手机。真实数据库无变化，已有160项后端验收覆盖被复用导出，不能将前端自测当新模型或外部平台验收。

后续仍需持久题库/人工题目、错题历史、通知送达和间隔算法；向量检索、长文深度理解、生产/异地门禁也未通过本模块补齐。

本轮702非集成/39Node与静态构建通过；真实Chrome控制台12/12包括本模块流程、桌面/手机截图已目视，结果与最后构建复核见PROGRESS顶部。没有新增后端/schema/外部付费请求；保留原导出和会话实际服务基线。
