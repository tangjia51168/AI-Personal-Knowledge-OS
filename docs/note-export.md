# 单版本笔记导出

知识页和总结结果页可下载当前已保存修订的 Markdown、HTML、JSON、纯文本。
接口为 `GET /api/v1/spaces/{tenant}/notes/{note}/revisions/{revision}/export?format=markdown|html|json|text`，
默认 Markdown。每次重新验证身份、有效成员、租户和笔记/修订/来源/快照关系；不依赖客户端已加载内容授权。
历史版本固定到明确 revision UUID，不会悄悄切换为最新版本。无新表或迁移。

Markdown 按字节保留原不可变修订（含原限制和个人理解声明）；JSON 使用
`knowledge-note-export-v1` 格式，含笔记ID、修订版本/作者/时间/基准版本、结构化内容、原 Markdown
及其 SHA-256、original/canonical 来源链接、快照元数据/原响应摘要/限制和本修订引用的证据原文。
纯文本按结构化章节组织，不从 Markdown 反向剥离；HTML 为该文本的完整 HTML 转义静态文档，
使用 UTF-8、`pre` 和内嵌拒绝外部资源/脚本/表单的 CSP，没有外部样式、图片、字体或主动链接。
HTML 不把原文 HTML、Markdown 链接或脚本解释为可执行标记。

所有响应为 attachment、no-store、nosniff 和 sandbox CSP，文件名仅服务器验证的修订 UUID，
不会把用户标题写进响应头。四种格式 UTF-8 输出最大 1MiB；超限拒绝，不截断或伪造完整导出。
BFF 只放行精确路径的 GET 和固定格式参数，拒绝重复或无效 format；普通请求时限不扩大。

JSON/HTML/纯文本保留来源类型、人工导入与模型/人工版本区别、缺失章节、partial 证据范围、
来源限制和个人理解未经核验说明。有效引用不代表事实或语义蕴含得到验证。
JSON 引文可能含不可信原文，导入方不得将其作为指令或直接注入 HTML。
文件含用户知识内容，应由用户自行安全保存；下载后的文件无法随成员撤权远程撤回。

只导出一个修订及其引用证据，不含全部快照正文、其他笔记/版本、标签、双向链接或逐段批注，
不是全空间备份或可恢复归档。不新增模型、网络采集、存储对象、任务、业务审计或付费请求。
页面失败不生成文件，允许显式重试；未保存草稿不会被导出。新修订/空间切换会重建导出状态。
PPT、图文、流程图、Obsidian 打包、批量/完整备份与导入仍未实现。

实际检查与真实验收结果见 PROGRESS.md；本模块不代表生产漏洞门禁或完整 Phase 0/Phase 1 完成。
