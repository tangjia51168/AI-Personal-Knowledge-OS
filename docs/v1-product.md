# 第一版可运行产品

本轮以本机个人工作空间为第一版基础范围：登录后可发现全部组件，从资料进入、证据笔记、组织检索、学习复习走到导出，查看后台任务及权限边界。完整12主线目标仍以 mainline-acceptance.md 为准，不删除未实现目标，也不以测试数量推导完成率。实际检查以PROGRESS.md顶部为准，代码实现与外部推理实测分开记录。

## 打开与使用

现有隔离实例：[工作空间](http://127.0.0.1:13000/account)、[项目进度及成果](http://127.0.0.1:13000/progress)。这是本机验收数据实例。使用自己创建的账户；自动浏览器检查的临时账户结束后清理，无通用演示密码。会话有效12小时，刷新和同源新标签页可继续使用，到期重新登录；退出会撤销后端会话，见docs/account-session.md。

1. 收件箱检查并保存链接，选择来源后导入有权使用的正文、SRT/WebVTT，或UTF-8 TXT/MD/CSV/JSON文件。文件只填入预览，确认导入后才发送。
2. 刷新导入状态，打开真实Worker保存的快照。展开“不调用模型，创建人工证据笔记”，从服务器片段选择并确认；无需模型也能建立笔记。
3. 知识库检索、阅读、修订和批注；维护主题/标签、人工概念及双向链接。学习区保存个人状态与复习提醒。
   已保存版本可展开“证据自测”，先写回忆后对照参考/原文，人工自评并重练本次待练题卡；不调用模型，结果仅本次页面，详见docs/evidence-recall.md。
4. 研究区查证据/固定版本；有获准供应商时可逐次授权生成基础证据回答，无证据直接报告不足，不调用模型。重登录后可读取本人最近20条记录。
5. 导出中心选择固定修订，下载八格式或明确选择最多20个修订批量导出。
6. 任务中心查看实际状态，保存/暂停/恢复公开来源计划。采集关闭时明确报COLLECTOR_DISABLED，不报告同步成功。
