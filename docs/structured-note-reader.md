# 结构化笔记阅读与证据定位

知识笔记及总结结果复用已保存的不可变修订，显示概述、核心结论、步骤、案例、数字、启发、
缺失信息和个人理解。目录按钮支持键盘定位，正文按纯文本展示，不解析HTML、Markdown链接或远程资源。
原始Markdown仍在可展开的只读区域，原字节导出与编辑、批注不改变。

点击引用编号，页面按需GET现有的指定修订JSON导出；沿用身份、有效成员、显式租户联查与FORCE RLS。
不新增API、BFF白名单、数据库表、Worker、依赖或模型调用。返回结果须匹配笔记、修订及快照ID，
所有所需引用必须存在且不重复，大小最多1MiB；引用仅在当前阅读区内定位，不写浏览器地址或持久化存储。
切换笔记/修订/空间/会话时卸载并取消旧请求；失败清空旧证据，提供手动重试。
原始URL仅按文本展示，不自动访问，也不把导入内容中的URL变成可执行链接。

未生成章节会明确列出，不补造内容；证据范围显示真实片段数，不转换为事实准确率、语义覆盖率或学习进度。
人工导入、元数据限制、个人理解和仅分析前缀均保留提示。引用有效不代表事实已核验，
不猜测视频时间点，尚无音视频播放定位或学习状态/计划/提醒。

## 验证

- 纯函数边界测试：结构/配额/重复编号、范围一致性、修订与快照绑定、引用缺失、恶意纯文本。
- 真实浏览器用现有隔离账户与明确标识的协议夹具验证目录、定位、断网失败/重试、历史版本与移动布局。
  协议夹具不是平台采集或模型推理的成功凭证。
- 安全截图只截阅读区域，不包括登录字段或凭证；检查的实际结果以PROGRESS顶部为准。
- 无schema或后端变化，不声称本轮重新执行数据库恢复或旧99项数据库验收；新镜像未复扫，
  原漏洞门禁失败和生产资源/Ollama未验收不因本模块而通过。
