# 人工笔记双向链接

人工链接关联同一空间内的两篇完整笔记，与具体修订解耦。数据库按两个笔记 UUID 规范化保存一条无方向记录，
所以任一端读取都能看到同一链接；新增或查看历史版本不会复制、迁移或删除链接。

当前链接只表达“空间成员手动建立了相关入口”。生成方法固定为 `manual`，置信度为空；
它不表示支持、反驳、解释、因果、相似度或事实核验。已有一/两跳[人工链接局部图谱](manual-note-graph.md)，
语义关系、关系证据与完整知识图谱仍属于后续模块。

GET `/spaces/{tenant}/notes/{note}/links` 返回最多 50 条有效链接及对端最新标题/版本。
PUT/DELETE `/spaces/{tenant}/notes/{note}/links/{target}` 建立或停用链接，重复请求保持幂等；
每篇笔记最多 50 条、每空间最多 1000 条。页面可按最新标题/Markdown 搜索前 20 个候选、关联、移除，
并从任一端打开关联笔记。

固定 0019 迁移使用两组同租户复合外键、规范顺序检查、FORCE RLS 和最小列更新权限。
写操作在租户锁后重新验证会话与成员，状态和 `notes.linked`/`notes.unlinked` 审计同事务提交。
停用记录保留创建者、最后操作者和时间，重新建立复用同一关系记录。

当前验收状态和实际证据见 [PROGRESS](../PROGRESS.md)。
