# Phase 1 来源入口边界

后续增量：已加入实际公开连接器、独立采集Worker、不可变快照和显式AI笔记消费者，
详见[内容与知识链路](content-knowledge-pipeline.md)。下文的“不访问网络”仅指检查与保存来源接口本身；
平台真实可达性及新增模块验收以PROGRESS.md最新节为准。

当前交付是来源入口的安全预处理与候选入库。受保护的
`POST /api/v1/spaces/{tenant_id}/sources/inspect` 只接受已验证成员的粘贴文本，
提取最多 20 个 `http`/`https` 候选，返回 `original_url`、去片段后的
`canonical_url` 和固定拒绝原因。接口按请求来源及已验证用户经过 Redis 限流；文本最多 16KiB UTF-8，
整个 JSON 请求体（含转义字符、幂等键）最多 17KiB，API 与 BFF 均在解析前限制真实字节。
检查不访问网络或写入数据库；恰好 20 个候选不会误报截断，超过时显示截断且禁止保存。

`POST /api/v1/spaces/{tenant_id}/sources` 复用同一解析边界，把一批接受/拒绝结果在单一租户事务中
保存到 `source_batches` 与 `sources`，必须携带 UUID `idempotency_key`。相同成员、键和原始文本的重试
返回同一批次，不增加审计；键被用于其他文本或其他成员时返回 409。空候选或超过 20 个候选时整批拒绝。
写入前以 tenant→member 锁序复验成员，串行检查租户配额/去重，并在同一事务写入固定审计事件。
每空间每天最多 100 批，总候选最多 10,000 条。`GET` 同一路径只返回当前成员空间最近 100 条候选。

接受项保留原始 URL，规范值去掉 fragment、统一域名/默认端口；不重排 query 或猜测平台身份。
用 `(tenant_id, canonical_sha256)` 唯一约束避免长 Unicode URL 超过 PostgreSQL btree 索引长度，命中时再比较
完整 canonical。重复候选以 `DUPLICATE_CANONICAL_URL` 拒绝并保留安全原始链接；其他拒绝项将原始值
替换为 `[blocked]`，不把内嵌凭据/过长危险内容长期入库。没有持久化整段分享文本，只有批次 SHA-256。
两表 FORCE RLS、租户复合外键、INSERT actor 校验，运行角色仅 SELECT/INSERT，不允许更新或删除。
这仍不触网、不执行重定向、不调用平台 Adapter；接受仅表示可保存 URL 候选，不表示采集成功。

账户收件箱以检查时的文本和幂等键保存；编辑输入清空旧检查。保存响应失败后使用原键重试，
可手动刷新已保存候选，危险 URL 只显示文本；不会为任何候选显示虚假的抓取进度。

`apps/api/app/integrations/url_safety.py` 提供后续 Adapter 必须复用的边界：拒绝凭据、
本机/私有 IP、特殊主机名、控制字符、非法端口和非 HTTP(S) scheme；连接前及每次重定向后
必须重新解析 DNS，并拒绝任何私有、回环、链路本地、保留、组播或未指定地址。
该原语自身不连接网络；后续已交付的integrations/platforms连接器固定到已校验IP，并以原域名验证TLS，
避免检查与连接地址不同。生产仍须受限出口网络作为纵深防御。

来源快照、公开连接器、逐跳重定向与大小/时间边界已在后续模块交付，网页真实链路已通过；
B站两条用户输入HTTP412被拒，YouTube真实外部连接未验收，短链与各平台分享格式仍待完善。
检查/保存接口本身继续不触网，不得把URL接受视为采集成功；公网门禁见PROGRESS.md。

本模块实际验收：0012隔离库36/36集成（含新增8项来源API/DB测试）、319非集成与静态构建、
Chrome12/12（含真实断网原键重试）、21表同机加密恢复及演练后运维/本机HTTPS均通过。
证据与局限见PROGRESS.md顶部；这些结果不替代平台Adapter、生产漏洞修复或异地恢复验收。
