# 逐段人工批注

批注绑定不可变笔记修订及结构化章节中的段落索引，服务器保存并校验原段引文、作者和时间。
不按字符串搜索迁移到新版本，不改变笔记正文、来源证据或现有 Markdown 下载。
当前只追加，暂不编辑/删除；内容明确标为未经来源或事实核验的个人观点。

GET/POST `/spaces/{tenant}/notes/{note}/revisions/{revision}/annotations` 先验证身份及成员。
写入在租户锁后复验会话和成员，UUID 幂等键绑定作者、目标版本、段落、原文和正文；
同键同请求返回原记录，不重复审计，同键不同内容返回409。
正文最多2000字符/8000 UTF-8字节；每笔记100条、每空间1000条，配额和审计与追加同事务。
读取每页20条，最多50条；游标仅可来自当前租户、笔记和修订。

固定0018迁移增加复合外键、FORCE RLS和SELECT/INSERT授权；数据库追加策略还独立验证原段引文和操作者。
页面提供段落选择、原文预览、草稿导航保护、明确放弃、失败原键重试及有界分页。
批注以文本渲染，不执行HTML。未请求平台、模型或用户设备。

本模块550非集成/静态/构建、83真实加固/重启/受限S3、Chrome23、30表恢复和最终运维/本机TLS已通过。
最新20镜像扫描完整但漏洞门禁仍失败；不代表完整Phase0/Phase1或生产条件通过。
实际检查证据见 [PROGRESS](../PROGRESS.md)。
