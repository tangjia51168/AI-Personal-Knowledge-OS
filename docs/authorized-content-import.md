# 授权正文与字幕导入

当公开网页缺正文或平台拒绝访问时，用户可以自行提供有权使用的正文/字幕。导入内容是新的人工快照，
不改变远端采集的失败结果，不代表系统取得或核验了原视频。不会上传平台 Cookie、访问来源、下载视频或调用模型。

## 使用

在账户收件箱保存来源链接，展开该来源的“导入授权正文或字幕”，填写标题、选择格式和内容类型、粘贴文本并确认授权。
支持纯文本、SRT 与 WebVTT；字幕格式只能保存为转录内容。第一版不解析 PDF、Word、音视频或压缩文件。
字幕仅支持按开始时间排序的基本 cue；不支持 WebVTT NOTE/STYLE/REGION、cue settings 等扩展，遇到这些格式会明确拒绝。
任务保存后可刷新状态与快照；已有版本保留。请求失败且未编辑内容时重试沿用原幂等键，避免重复任务。
成功后另行授权才可生成 AI 笔记；导入本身没有模型费用。

每份输入最多 60,000 字符且不超过 65,536 字节 UTF-8；整个 JSON 请求最多 128KiB，API/BFF 分别检查流式请求。
正文只做有界文本规范化，字幕保留时间标签，不核验与音视频是否对齐。非法/空字幕拒绝，不猜测补全文本。
HTML/脚本不会执行，内容展示为纯文本。分段导入必须由用户主动提交，不自动拆分、采集或产生费用。

## 持久化与权限

`POST /api/v1/spaces/{tenant_id}/sources/{source_id}/imports` 接收
`idempotency_key/consent/title/text/format/content_kind`，只接受已有且仍可访问的来源。
真实身份与成员验证、tenant→member 锁、任务/快照配额和幂等检查后，在同一事务写 `source_import` 任务与 outbox。
队列只传 opaque dispatch ID；正文保存在受租户 RLS 保护的任务记录，不作为队列参数传送，不写入日志。

独立 Worker 从数据库复核真实任务、请求人/成员/来源，处理后再检查取消/权限与配额才提交快照。
固定 0015 迁移追加 `source_snapshots.provenance`，已有快照默认 `platform_collection`，新人工导入为 `user_import`。
INSERT RLS 将 actor、来源 UUID、running 任务种类与 provenance 绑定；租户复合外键及 SELECT/INSERT 追加权限保留。
`raw_sha256` 对人工快照是导入原 UTF-8 文本摘要；对采集快照仍是远端原始响应摘要。
人工快照的 `fetched_url` 是兼容字段，只表示关联 canonical URL；界面明确导入时没有访问该地址。

人工快照及随后笔记必须保留“用户提供、未核验与原平台一致”的范围提示。模型提示和服务端保存均保留这一事实，
不能由模型自行省略。证据引用只绑定这份不可变人工快照，不证明原视频内容或字幕时间真实性。

## 验收

解析、请求边界与类型检查可离线运行；真实验收使用隔离 acceptance 数据库、Redis 和独立 Worker。
API→outbox→Redis→Worker→人工快照、跨租户拒绝、幂等/重放、追加权限与浏览器授权流程分别验证。
测试使用明确标注的人工文本，不把测试字幕当成用户两条 B站视频的真实字幕，不新增模型请求。
具体结果与报告见 PROGRESS.md；本机导入通过不解除公开部署、漏洞、Ollama 或平台采集门禁。
